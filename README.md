# Сачок для думок

Міні-гра для онлайн-уроку з soft skills «Датчик хвилювання» (LetMe/teens, 9–10 років).
Викладач показує її через демонстрацію екрана в Zoom і сам натискає. Діти називають номер хмаринки вголос.

Уся гра в одному файлі `index.html`: без збірки й без залежностей.

## Як грати

| Клавіша | Дія |
|---|---|
| `1`–`8` | впіймати хмаринку з цим номером |
| `H` | показати або сховати підказку-питання |
| `Пробіл` | перетворити думку-шкідника на думку-напарника |
| `Enter` | покласти думку-напарника в Банку пілота (або клік поза карткою) |
| `Esc` | закрити хмаринку без перетворення |
| `R` | скинути гру (з підтвердженням) |
| `?` | шпаргалка з клавішами |

Клавіші працюють на будь-якій розкладці, зокрема на українській.
Звук вимкнений за замовчуванням, кнопка 🔇/🔊 у правому верхньому куті його вмикає.
Коли в банці 3 думки, гра показує фінал. Потім можна грати далі, а кнопка «Скинути» починає гру з нуля.

## Як змінити думки

Відкрийте `index.html` і знайдіть на початку `<script>` масив `THOUGHTS`:

```js
const THOUGHTS = [
  { pest: "З мене будуть сміятися.",
    hint: "Над чим зазвичай сміються — над людиною чи над ситуацією? І скільки це триває?",
    partner: "Навіть якщо хтось хихикне, за 5 хвилин усі забудуть. А я вже відповів." },
  ...
];
```

- `pest`: думка-шкідник (темна хмаринка);
- `hint`: підказка-питання (жовта картка, клавіша `H`);
- `partner`: думка-напарник (жовта хмаринка після перетворення).

На полі завжди 8 хмаринок, тому в масиві має бути 8 записів.
Розмір шрифту в хмаринці підбирається сам під довжину тексту. Краще, щоб думка не була довшою за ~90 символів.
Константа `GOAL` під масивом задає, скільки думок треба для фіналу (зараз 3).

## Зображення Леї

Покладіть картинку в `assets/lea.png`. Найкраще підійде PNG з прозорим фоном, вертикальний, приблизно 2:3.
Якщо файлу немає, гра показує вбудований SVG-малюнок.

## Як опублікувати на GitHub Pages

1. Закомітьте `index.html` (і `assets/lea.png`, якщо він є) у гілку `main`.
2. На GitHub відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** виберіть **Source: Deploy from a branch**, гілку `main` і папку `/ (root)`, потім натисніть **Save**.
4. За хвилину-дві гра буде доступна за адресою `https://<користувач>.github.io/<репозиторій>/`.

Перед уроком відкрийте сторінку на весь екран (`F11`) і показуйте в Zoom вікно браузера.
